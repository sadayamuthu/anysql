## Wanted

anySQL has one maintainer, and wants more, especially from organizations not
already represented. Areas where help would make the biggest difference:

- adapters for other providers (Gemini, Bedrock, the OpenAI Responses API),
- a LangChain `BaseCallbackHandler` and other framework integrations,
- OpenTelemetry GenAI import and export,
- the `anysql-proxy` package.

If you're interested, start with an issue labelled `good first issue` or
`help wanted`, or open an issue to say what you'd like to work on.
